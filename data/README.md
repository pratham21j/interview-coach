# Liveness Detection Dataset

This directory contains the dataset used for facial presentation
attack detection.

Classes:

- `live` - genuine/live face samples
- `spoof` - presentation attack samples

Dataset split:

- `train` - model training
- `val` - hyperparameter/model selection
- `test` - final evaluation

The raw dataset should not be committed to GitHub.
Only dataset documentation and preprocessing scripts should be tracked.
